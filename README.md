# web-application-security-monitor-and-alert-system
a web application that monitors the requests &amp; activities and generate the alerts if any suspicious activity is detected. 
All these applications handle important information of users that can become targets for different types of attacks, such as SQL injection, Cross-site scripting, brute force and unauthorized acess can disrupt the security of a web application. One of the main problems is detecting suspicious activities that cannot always be noticed immediately. If all these suspicious activities are not recognised, it can be very difficult to handle the incidents that can arise later after that. Therefore, proper system and login updates should be given. So, our project topic itself provides web application security and is made to create a simple simulation that can help in recognising activities done suspiciously. Our project will maintain all the logs of unauthorised activities and provide login alerts when somebody unknown tries to perform something suspicious, so that the administrator can take action towards it. With the help of this project, we want to understand unnecessary logins in web platforms. This project will provide us with practical knowledge about how web application security can be achieved that will help in the overall security of web applications
